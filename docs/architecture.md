# Архитектура проекта

## Обоснование структуры

Выбран тип проекта — **веб-приложение** (Flask + HTML/CSS/JS).

- `src/` — исходный код: `app.py` (фабрика приложения), `routes.py` (маршруты),
  `static/` (CSS, JS), `templates/` (HTML-шаблоны).
- `tests/` — автотесты (pytest) с использованием test_client Flask.
- `docs/` — документация и обоснование структуры.
- `assets/` — статические ресурсы для документации (изображения, шрифты).
- `.github/workflows/` — CI для автоматического запуска тестов.

## Поток выполнения

1. Клиент запрашивает `/` → `routes.index` → рендер `index.html`.
2. Кнопка на странице вызывает `/api/health` → JSON `{"status": "ok"}`.
3. Тесты проверяют оба маршрута через `app.test_client()`.

## Разделение ответственности

- `app.py` — создание и конфигурация приложения.
- `routes.py` — бизнес-логика маршрутов (легко расширять).
- `static/` и `templates/` — представление, отделено от логики.
